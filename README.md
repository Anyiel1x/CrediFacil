# CrediFácil Financiera - Prototipo Front-End

## Tecnologías que usamos
* HTML5 usando las etiquetas correctas (header, main, nav, section, footer).
* CSS3 para los estilos y diseño responsivo (para que se adapte a celulares y computadoras).
* No usamos frameworks como Bootstrap o Material-UI, ni programación backend, para apegarnos a lo que pedía la rúbrica de la actividad.

## Declaración de uso de IA
Para este proyecto, el equipo utilizó herramientas de Inteligencia Artificial como apoyo para resolver dudas y organizar el trabajo. Específicamente nos ayudó a:
* **Guia de estructuración del código:** Nos orientó sobre cómo armar el código en HTML5 puro para cumplir con la rúbrica.
* **Estilos globales:** Nos dio sugerencias sobre cómo estructurar nuestro archivo CSS universal para que el diseño fuera igual en todas las pantallas.
* **Manejo de GitHub:** Nos sirvió de guía paso a paso para entender cómo trabajar en equipo usando ramas (branches), hacer los Pull Requests de forma segura y armar el Kanban sin sobreescribir nuestros archivos.
* **Formato:** Nos ayudó a darle el formato correcto a este documento README.
